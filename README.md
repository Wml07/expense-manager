# 开销管家

一个跑在命令行里的小助手：**问它问题，它只回答你自己资料里写过的内容；资料里没有的，它直接说"资料里没写"，不含糊编造。**

---

## 怎么跑

```
cd D:\WB01\2026-08-11-10-58-12\projects\expense-manager
python zhushou.py
```

> 解释器用 `D:\python3.11.8\python.exe`（系统那个）。本机 `.workbuddy` 自带的 Python 没装 `openai` / `dotenv`，跑不起来。

跑起来长这样：

```
===== 开销管家 =====
1. 记一笔账
2. 问个问题
3. 退出
请输入编号:
```

| 选 | 现在能干什么 |
|---|---|
| `1` | ⏳ 还没接（下一课接记账） |
| `2` | ✅ 提问 → 去资料里检索 → 分数太低直接拦下 → 交给 AI 回答 |
| `3` | 退出 |
| 其他 | 提示重新输入，不会崩 |

## 文件夹里都有什么

| 位置 | 是什么 |
|---|---|
| `zhushou.py` | **门** —— 摆菜单、收输入、显示结果 |
| `gongneng.py` | **业务** —— `wen_wenti(问题)`：检索 → 闸门 → 问 AI |
| `工具箱/` | **共用设施 + 开发过程**：`tools.py`（连服务、三套人设）、`xiangliang.json`（向量库）、以及一路写过来的 AI 脚本 |
| `练习/` | 全部基础练习（`p1`–`p16`、`review1`–`review7`…）和它们的账本数据 |

三层各管一件事：

```
zhushou.py   →  只管"问用户要什么"
gongneng.py  →  只管"把这件事干出来"
工具箱/tools.py → 只管"连服务"（聊天一个 client、向量一个 client）
```

以后加功能，只在 `gongneng.py` 里加函数 + 在 `zhushou.py` 加一条岔路，**互不干扰**。

## 它靠什么保证不瞎编

| 层 | 手段 | 管什么 |
|---|---|---|
| 提示词 | `SHEZHI_ZHISHI` 铁律（资料里没写就直说，不许推测） | AI **怎么说话** |
| 代码 | `if 最高分 < 0.5: return "资料里没写"` | **该不该说话** |

**0.5 这条线是量出来的，不是拍脑袋定的**：资料里确实有答案的问题，最高分落在 0.570 ~ 0.722；资料里压根没有的，落在 0.383 ~ 0.494。线画在两堆中间的空档里 —— 这就是阈值标定。
